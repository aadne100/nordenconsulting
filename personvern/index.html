Personvern

Når du tar kontakt med meg, bruker jeg opplysningene dine for å svare og følge opp det du spør om.

Kontaktskjemaet

Skjemaet ber om navn, e-postadresse og melding. Bedriftsnavn er valgfritt. Meldingen sendes gjennom Formspree. Unngå å skrive sensitive opplysninger i meldingen.

Du kan også kontakte meg direkte på adne@nordenconsulting.no eller 905 27 474.

Tjenester nettsiden bruker

Nettsiden publiseres med GitHub Pages. Bilder, video og skrifttyper leveres som egne filer. Det er ikke lagt inn analyseverktøy, markedsføringspiksler eller eksterne videospillere i denne versjonen.

Les Formsprees personvernerklæring og GitHubs personvernerklæring for informasjon om deres behandling av data.

Spørsmål og sletting

Kontakt Ådne Bjella på adne@nordenconsulting.no hvis du har spørsmål om opplysningene dine, vil rette dem eller be om sletting.
